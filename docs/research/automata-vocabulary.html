Hermes automata vocabulary

These terms describe registered automata and their recorded transitions. Each term has one meaning across the compendium and graph.

Terms

automaton
One registered state-and-transition structure for one family and kind. Machine is an informal synonym.
state
One node in one automaton.
formal state name
The display name q0, q1, and so on within one automaton.
code name
The Prolog atom for a state, such as q_start or q_accept.
plain-language state label
The literature-facing description attached to a state.
start state
The state where an automaton begins.
accepting state
A state designated as an accepted endpoint.
transition
One directed move from a source state to a target state, labeled by a local action.
local action
The action name authored on one transition.
canonical action
A normalized action name used to compare local actions across automata.
borrow
A canonical action name shared by two or more automata. A borrow asserts no equivalence between automata and no prerequisite order.
conserving
A semantic class for a canonical action recorded as preserving the relevant object or relation.
deforming
A semantic class for a canonical action recorded as changing the relevant object or relation.
neutral
The semantic class used when no conserving or deforming classification is recorded. It does not assert that the action has no mathematical effect.
runtime trace
The ordered steps returned by one runner invocation.
action sequence
An ordered list of action names independent of one runner invocation.
algorithm
A specified procedure for producing a result. An automaton is an algorithm only when a procedure claim is specified and supported.
family
The arithmetic or content grouping, such as fraction or counting.
kind
The registered subtype within a family. A family and kind together identify one automaton.
domain scene
The contextual SVG placed beside one automaton.
family path composite
The action paths of all automata in one family, merged at shared prefixes and identical suffixes. Loops are not unfolded.
path point
A node in a family path composite, labeled p1, p2, and so on. Path points are not states of any single automaton.
recorded transition graph
The graph formed by the transition-table rows recorded for one automaton.
branching
A recorded transition graph has a source with more than one distinct outgoing action-and-target pair.
loop
A transition returns to a state already on its graph path. A self-loop is included.

Dark, rust, and muted are color names used in legends. They are not semantic classes.

Formal tuple

An automaton entry uses this tuple:

M = (Q, Σ, δ, q0, F)

Q
the set of states
Σ
the local action alphabet
δ
the transition relation
q0
the start state
F
the set of accepting states

How branching is computed

The structural class uses both static and observed transition-table rows. Most branching sites come from that provenance union. The recorded relation does not establish that a runtime runner makes a nondeterministic choice.

This vocabulary applies to the automata compendium and the automata graph.
