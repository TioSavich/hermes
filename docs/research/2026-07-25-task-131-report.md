## Runnable input boundary

Thirty-seven target automata already fit the worker's integer-pair or
fraction-pair input forms. Six runner clauses consume compound terms. The worker
adapter now decodes three corresponding JSON forms:

- `fraction_solve` becomes `solve(P, Q), Total`.
- `rational_limit` becomes
  `rational_expression(NumeratorCoefficients, DenominatorCoefficients),
  limit_at(A)`.
- `terminal_path_tree` becomes a list of
  `terminal(Winner, probability(Numerator, Denominator), Events)` terms and a
  `stake(Value)` term.

These forms preserve the runner clauses' input structures at the JSON boundary.
