# Borrowed-transition audit

Date: 2026-08-06

## Scope and decision rule

This is a static audit of the live tree. No checks, generators, Prolog queries, or Git commands were run. The graph reports 259 deforming edges: 29 `context_sensitive_or_inefficient`-only and 58 mixed, so the requested pool contains 87 transition rows (`docs/research/assets/automata/full_graph.json:203-228`). Those rows collapse to 38 family/kind candidates in the authored ledger (`knowledge/strategies/deformation_validity.pl:26-535`). I count a candidate as a borrowing only when the repository names a practice or a bounded input context in which the produced artifact is licensed. Numerical coincidence by itself is not a home practice: the coincidence file explicitly limits each profile to its finite grid and requires per-input separation before diagnosis (`knowledge/strategies/deformation_coincidence.pl:8-24`).

The vocabulary supports this distinction. `record_viability` records per-input contextual correctness (`knowledge/strategies/action_vocabulary_map.pl:307-310`); `substitute_count_for_measure`, `substitute_symbol_reading`, and `treat_relevant_as_irrelevant` name transfers that become illicit only when the borrowed result is made to answer the receiving practice's question (`knowledge/strategies/action_vocabulary_map.pl:357-366`, `knowledge/strategies/action_vocabulary_map.pl:375-378`). This report therefore describes a misconception under erasure: it classifies a doing and its license, not a learner deficit.

### Mediant precedent and code-level repetition

The precedent is stronger than an accidental agreement. `add_numerator_denominator_sum` constructs `(a+c)/(b+d)`, checks it against the requested sum, and separately records that the result lies between the inputs (`knowledge/strategies/math/smr_frac_common_unit_add.pl:121-155`, `knowledge/strategies/math/smr_frac_common_unit_add.pl:170-182`). Its two deforming ledger edges are objective-invalid because they omit the common-unit obligations of fraction addition (`knowledge/strategies/deformation_validity.pl:180-181`), and its sum coincidence profile is 0/1764 (`knowledge/strategies/deformation_coincidence.pl:100-101`). The repair is therefore a claim change, not a lucky-input gate: name the result `mediant` and its licensed construction is betweenness.

The live duplicate artifact verifies 50 groups containing 210 rules, with 160 redundant relative to one group-mate on the battery (`.bigred-collected/2026-08-02-automata-generality/badges.md:297-315`). The largest group contains 35 fraction rules with the componentwise-add output vector (`.bigred-collected/2026-08-02-automata-generality/badges.md:317-321`). This is not an exact-rule-text result: it is behavioral equality on at most eight same-domain inputs, and the artifact warns that members may separate on a ninth input (`.bigred-collected/2026-08-02-automata-generality/badges.md:595-597`). Code-level borrowing is established for the 35-member group only at that bounded level; the other 49 groups have no named home practice in this audit and do not enter the borrowing census.
