# Illustrative Mathematics teacher-guide Markdown corpus

These 1,308 `document.md` files are byte-identical copies of the local
Docling Markdown extractions under
`hermes/app/runtime/experiments/gemma4_tutor/docling/full-output/TeacherLessonGuides/`.
The directory structure is preserved, and `manifest.json` records each source
path, tracked path, byte count, and SHA-256 digest. Run
`python3 scripts/curriculum/sync_im_teacher_guides_docling.py --check` to verify
the tracked corpus.

curriculum, copyright Illustrative Mathematics. The K-5 guides are licensed
