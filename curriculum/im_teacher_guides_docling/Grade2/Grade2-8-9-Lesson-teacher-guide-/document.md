## Goals

- Explain (orally) strategies for finding the total number of objects in an array.
- Match (orally) expressions with equal addends and arrays that represent the same value.

## Lesson Purpose

The purpose of this lesson is for students to make connections between the structure of an array and expressions that represent the sum of the number of objects in each row or column in an array.

## Narrative

In this lesson, students match expressions with equal addends to arrays and find the total number of objects in an array by finding the value of these sums. The primary focus of the lesson is on relating sums with equal addends to the structure of the rows and columns in an array in order to build foundations for using arrays to represent multiplication in grade 3.

The arrays in the lesson also invite students to decompose the array in ways that make sense to them. It is important to recognize other ways students may use expressions to represent arrays.
