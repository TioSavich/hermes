## Lesson Purpose

The purpose of this lesson is for students to draw a given number of images.

## Narrative

In a previous lesson, students created number posters by counting out groups of objects to match a given number. In this lesson, students complete the same activity, but they draw the groups of images to show each number. The same posters that were used in the previous lesson can be used in the first activity.
