## Goals

- Present (using words and other representations) a strategy for solving a 'how many groups?' or 'how many in each group?' problem.
- Represent division situations using division expressions.

## Lesson Purpose

The purpose of this lesson is for students to write division expressions to represent division situations and solve 'how many groups?' and 'how many in each group?' problems.

## Narrative

Students sort division situations based on whether the number of groups is unknown or the number of objects in each group is unknown and write division expressions to represent each situation (MP2). Students then use the representations they have learned in this section to solve division problems.
